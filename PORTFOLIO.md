## Short description

Built a demographic customer-segmentation analysis using reusable preprocessing, PCA, and k-means. Reduced 63 features to 34 principal components retaining 90.43% variance, identified eight population segments, and compared customer representation while accounting for missing-data exclusions. Completed and passed as part of Udacity's Introduction to Machine Learning with PyTorch Nanodegree.
